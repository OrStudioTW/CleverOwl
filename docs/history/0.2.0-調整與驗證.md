參考檔：使用者提供 Owl Auxiliary 1.0.1.0 (`com.owl.auxiliary`)，SHA-256 `93f355ffa593e7dca1d962ccdb76b53dc072e77e9f234e8c0ee789497b2be7bc`。只進行靜態分析，未執行或安裝；該檔有控制流程／字串混淆與 native 方法，因此只採用可解出並核對的設計，不宣稱已完整還原。分析暫存在 `work/reference`，不包含於交付原始碼。

- 會員：參考模組以 `User(adsConfig=` 特徵定位模型，在建構前修改參數，並使用 `SubscriberLevel.GOLD`。新版採同樣的建構前輸入策略，但保留 Super=`PREMIUM`、Max=`GOLD` 選擇；依現有原版 APK 核對實際 85／109 參數模型，處理快取還原時的衍生欄位，不照搬參考模組的舊索引或額外電話／布林資料改動。若結構不符則跳過。此操作不建立伺服器訂閱。
- 計時：參考模組定位 `TimedLightningPractice`、`TimedMatchPractice`、`TimedMultiSessionPractice`，在建構前延長時間。已核對混淆常數為 60,000；新版延長 Lightning／Match 第 0 個參數、MultiSession 第 1 個參數，保留其 XP、關卡數與其他資料。這是至少約 16.7 小時的練習初始時間，不是所有模式真正無限。原本 Tick 最低 2 秒的備援仍只在已核對版本及 SHA 上使用。
- 載入／設定：使用應用程式 Context 的 ClassLoader，保留既有設定相容與預設關閉，新增首次設定提示、功能設定及 hook 命中日誌。註冊成功與真正命中分別記錄。

會員與三種初始時間的定位改以唯一字串與建構式結構匹配，未再要求完全相同 APK 雜湊；這不代表其他版本已驗證。倒數 reducer 備援仍限定樣本，避免對未知判定分支外推。

## 截圖中的 XP 預估

使用者指定的位置是課程開始前按鈕「繼續 +25 經驗」。在已分析 Duolingo 6.103.6 (2488) 的資料鏈為：

`XpBoostMultiplierInputs (eqb0)` → `qvr.invokeSuspend` → `ksb0` 預估計算 → `Learn.expectedXp (enr.b)` → `PopupActionContent (m0m.e)` → 「繼續 +XP」複數資源文字。

原始 DEX 顯示預估計算使用同一個最高有效倍率，再向上取整；課程計算也消費同一份 XP 輸入。因此維持共同倍率 hook，沒有再對按鈕數字額外相乘，也沒有直接替換翻譯文字。新增唯讀預覽觀察，最多記錄 8 次數值，協助區分倍率入口及預覽入口是否命中。

無其他倍率且基礎 XP 為 25 時，額外 ×3 的預估為 75。若原來已有加倍或非整數倍率，會由原生計算疊加後取整；不能把畫面預估當作伺服器入帳證明。
