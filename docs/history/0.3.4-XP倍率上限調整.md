# 0.3.4-alpha：XP 倍率上限 ×3

2026-10-29，Asia/Taipei。

依使用者實測回報，高於 ×3 的倍率失效。本版設定頁只保留「維持原始倍率」「額外 ×2」「額外 ×3」。

啟用倍率修改時，原生加倍與選擇倍率合併後，最終上限為 ×3，避免疊加後超出有效範圍。

| 原生倍率 | 設定 | 最終倍率 |
| --- | --- | --- |
| ×1 | 額外 ×2 | ×2 |
| ×1 | 額外 ×3 | ×3 |
| ×2 | 額外 ×2 | ×3 |
| ×2 | 額外 ×3 | ×3 |
| 任何原生倍率 | 維持原始倍率／關閉修改 | 原生倍率 |

維持設定 schema 1。舊版合法高倍率（含 ×5／×10）在讀取時降為 ×3；設定頁會選中 ×3，下次儲存即寫回 3。其餘開關保留。非法或錯誤型別數值仍回到原始倍率，不會自動開啟修改。

已保留 0.3.3 的倍率入口、加倍旗標一致性修正與診斷功能。0.3.3 已有單堂 ×3 的實測證據：預估20→60、結算75、聯賽130→205且重啟保留；這項既有結果不代表 0.3.4 的新規則已完成實機驗收。×2、原生加倍疊加與其他功能仍待分別驗證。
