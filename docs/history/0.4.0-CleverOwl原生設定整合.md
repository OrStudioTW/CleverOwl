# CleverOwl 0.4.0-alpha：原生設定整合

2026-10-29，Asia/Taipei。

## 已實作

模組、啟動器與備用設定頁的顯示名稱改為 **CleverOwl**。套件識別、設定 schema 與簽章維持原有更新關係，供覆蓋安裝及保留既有設定。

對完整版本名、版本碼與 base SHA256 均匹配的 Duolingo 6.103.6 (2488)，在設定的「隱私設置」下方加入 **CleverOwl**。原生隱私列使用中間列樣式，CleverOwl 作為同組最後一列；隱私列仍呼叫原本的隱私導航回呼。沒有修改其他設定列或帳戶資料。

CleverOwl 頁面在 Duolingo 內以全頁視窗開啟，直接使用目標 App 的原生元件：

| 功能 | 沿用的原生元件 |
| --- | --- |
| 頁面、滾動與頂部操作列 | DuoComposeView2、SettingsPage、SettingsActionBar |
| 入口與分組切換列 | SettingsRowItem、GroupedListItemPosition |
| 總開關、限時練習開關 | SettingsToggle |
| 會員、XP、延期選項 | SettingsRadioButtonGroup、SettingsRadioButton |
| 背景、字體、配色、說明文字 | DuoTheme、SettingsSectionTitle、SettingsText |

頁面涵蓋總開關、原始／Super／Max、原始／×2／×3、六種延期選項及計時開關。保留最終 XP 倍率上限 ×3。右上角「儲存」提交並核對讀回值，成功後關閉頁面並提示重開 Duolingo；返回箭頭或系統返回會關閉頁面，未儲存的草稿不寫入。

即使功能總開關關閉，也會註冊設定入口。模組 App 保留同一份設定的備用編輯入口。未知 APK 會跳過這項固定結構的整合，不推定其他版本已適配。

## 設定保存

使用受限 ContentProvider 在模組 UID 下寫入既有共享設定，避免讓 Duolingo 直接寫入另一個 App 的私有檔案。接口只允許模組自身 UID，或套件名稱與原版簽章均符合的 Duolingo。只接受六個已知設定欄位、正確型別及 UI 可選值；不提供任意檔案或資料庫操作，不存帳戶識別或認證。

原生頁面與備用設定 App 使用同一份 schema 1 設定。完整關閉再重開 Duolingo 後，才會依新設定註冊原本未啟用的功能。

## 待實機確認

本輪未由代理安裝、操作手機或改動 LSPosed 設定。以下不能以單元測試或原始 DEX 核對替代：

1. 覆蓋安裝後，啟動器及 LSPosed 顯示 CleverOwl，既有設定仍存在。
2. 完整關閉再開啟 Duolingo，在設定的隱私列下方看到 CleverOwl；來回開啟或重組後沒有重複入口，原隱私頁仍可導航與返回。
3. 點開 CleverOwl，檢查原生字體、深淺色、滾動、系統邊界、返回與全部選項。
4. 儲存一組設定並重開 CleverOwl 頁面、備用設定 App 及 Duolingo，核對同一份資料與新功能註冊。將總開關關閉後，入口仍可開啟。
5. 未授權 App 的 provider 請求遭拒。單元測試已覆蓋識別判斷，但 Android Binder 的實際路徑仍待驗證。
